This is WinWS GUI.
It opens small window that accepts run parameters it text field and one button: run. When script is running then button caption changed to stop. 
If window is closed while running then it moves to tray. If it closed when is not runnig then it fully closed.
Run parrameters should be saved between runs. So when we runs this gui again it opens with last used parameter.
GUI is build with default system elements for windows platform.
